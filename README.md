# Aev0rnJP SPEED

**ワンタップでインターネット回線の速度をチェックできる、シンプルな速度測定ツールです。**

Web版とAndroidアプリ版を公開しています。ダウンロード速度・アップロード速度・Pingを測定し、接続しているネットワークから推定される回線事業者の情報も表示します。

## 使い方（Web版）

1. 上の「Web版」を開きます。
2. ページが表示されたら「速度を測定する」を押します。
3. Ping、ダウンロード、アップロードの順に自動で測定されます。
4. 測定が終わると、各数値が画面に表示されます。
5. もう一度測りたい場合は「もう一度測定する」を押します。

測定中は通信量が発生します。できるだけ正確に比べたい場合は、ほかのアプリの大きなダウンロードや動画再生を止め、同じ場所・同じ接続方法で測定してください。

## 使い方（Androidアプリ）

1. Android端末で「Android APK」のリンクを開き、APKファイルをダウンロードします。
2. ダウンロードしたAPKファイルを開きます。
3. Androidから許可を求められた場合は、内容を確認してこのファイルのインストールを許可します。
4. インストールを完了し、「Aev0rnJP SPEED」を起動します。
5. アプリ内の画面で「速度を測定する」を押し、測定結果を確認します。

Androidの設定や端末によっては、ブラウザやファイル管理アプリに「不明なアプリのインストール」の許可が必要な場合があります。インストールは自分で入手したAPKであることを確認して行ってください。更新時にインストールできない場合は、まず既存アプリと新しいAPKの提供元が同じか確認してください。アンインストールするとアプリ内のデータが消える場合があるため、必要なデータがないか確認してから行ってください。

## 測定項目

- **ダウンロード（Mbps）：** データを受信する速度の目安。Web閲覧や動画視聴などに関係します。
- **アップロード（Mbps）：** データを送信する速度の目安。ファイル送信や配信などに関係します。
- **Ping（ms）：** サーバーとの応答時間の目安。一般に数値が小さいほど応答が速い傾向があります。
- **接続キャリア・プロバイダー（推定）：** IP情報サービスから取得したネットワーク事業者情報です。実際の契約先やWi-Fi施設名を必ず特定できるものではありません。

## 測定結果について

測定結果は、Wi-Fiの電波状況、モバイル回線の電波、端末性能、VPN、混雑状況、測定先サーバーなどで変化します。1回の測定結果だけで回線全体の性能を断定せず、時間を変えて複数回測ることをおすすめします。

測定ではCloudflareの速度測定エンドポイントを使用します。回線事業者の推定表示ではIP情報サービス（ipwho.is）に接続します。そのため、測定や事業者情報の取得にはインターネット通信が発生します。表示される事業者情報は推定値であり、正確性を保証するものではありません。

## トラブルシューティング

- **ページが開かない：** インターネット接続を確認し、ページを再読み込みしてください。
- **測定に失敗する：** VPNや広告ブロック機能などの設定、通信制限、接続状況を確認して再試行してください。
- **事業者が「判定できません」と表示される：** IP情報サービスに接続できない場合があります。速度測定そのものとは別の機能なので、時間をおいて再試行してください。
- **結果が毎回違う：** 回線の混雑や電波状況などで変化するため、同じ場所・同じ接続で複数回測定してください。
