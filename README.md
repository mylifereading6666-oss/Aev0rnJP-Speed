# Aev0rnJP SPEED

**Aev0rnJP SPEED は、インターネット回線の通信速度を簡単に測定できるツールです。**

Webブラウザ版とAndroidアプリ版に対応しています。Ping・ダウンロード速度・アップロード速度を測定し、IP情報から推定したネットワーク事業者情報も表示します。

## 基本的な使い方

1. [Web版](https://mylifereading6666-oss.github.io/Aev0rnJP-Speed/)を開くか、Androidアプリを起動します。
2. 画面の **「速度を測定する」** を押します。
3. 自動測定が終わるまで画面を開いたまま待ちます。
4. 表示されたPing・ダウンロード速度・アップロード速度を確認します。
5. 再測定したい場合は、**「もう一度測定する」** を押します。

測定にはインターネット通信が必要です。測定中は通信量が発生します。

## 測定結果の見方

| 項目 | 単位 | 意味 |
|---|---|---|
| **Ping** | ms | サーバーから応答が返るまでの時間。一般に小さいほど応答が速い傾向があります。 |
| **ダウンロード** | Mbps | データを受信する速度。Web閲覧、動画視聴、ゲームのダウンロードなどに関係します。 |
| **アップロード** | Mbps | データを送信する速度。ファイル送信やライブ配信などに関係します。 |
| **接続キャリア・プロバイダー（推定）** | — | IP情報をもとに推定したネットワーク事業者情報です。必ずしも実際の契約先やWi-Fi施設名とは一致しません。 |

**注意：** 速度測定の結果だけで、オンラインゲームの快適さを完全に判断することはできません。ゲームではPingの安定性、パケットロス、サーバーまでの経路なども影響します。

## より安定して測定するコツ

- 大きなファイルのダウンロードや高画質動画の再生など、ほかの通信を一時的に止める。
- Wi-Fiで測る場合は、ルーターの近くで測定する。
- Wi-Fiとモバイルデータ通信を比較するときは、それぞれ接続を切り替えてから測る。
- 同じ場所・同じ接続方法で時間を変えて複数回測定する。
- VPNを利用している場合、VPN経由の結果になることがあります。

測定結果は、電波状況、端末性能、回線の混雑、VPN、測定先サーバーなどによって変化します。1回の結果だけで回線の性能を断定しないでください。

## Androidアプリのインストール

1. 上の **「APKをダウンロード」** をAndroid端末で開きます。
2. APKファイルのダウンロードが完了したら、通知またはファイル管理アプリから開きます。
3. Androidが許可を求めた場合は、内容を確認し、このファイルを開いたアプリからのインストールを許可します。
4. インストールを完了し、**Aev0rnJP SPEED** を起動します。
5. **「速度を測定する」** を押して測定します。

Androidのバージョンや端末によっては、「不明なアプリのインストール」の許可が必要な場合があります。**自分が公式リポジトリから入手したファイルであることを確認してから**インストールしてください。

更新時にインストールできない場合は、既存アプリと新しいAPKの署名が異なる可能性があります。アンインストールするとアプリ内データが消える場合があるため、削除する前に必要なデータがないか確認してください。

## トラブルシューティング

- **ページが開かない：** インターネット接続を確認し、ページを再読み込みしてください。
- **測定が始まらない／失敗する：** 接続状態を確認して再試行してください。VPN、広告ブロック、通信制限などが影響する場合があります。
- **測定中に画面が切り替わった：** もう一度ページまたはアプリを開き、再測定してください。
- **事業者情報が判定されない：** IP情報サービスに接続できない場合があります。速度測定とは別の機能なので、速度測定を再試行してください。
- **結果が毎回違う：** 通信環境は変化します。同じ場所・同じ接続方法で数回測り、傾向を比較してください。
- **APKをインストールできない：** ダウンロードが完了しているか、Androidの設定でインストールが許可されているかを確認してください。

## 通信・プライバシーについて

- 速度測定では、Cloudflareの速度測定用エンドポイントと通信します。
- 接続キャリア・プロバイダーの推定表示では、IP情報サービス **ipwho.is** に接続します。
- そのため、速度測定や事業者情報の取得にはインターネット通信が発生し、接続先サービス側でIPアドレスなどの通信情報が扱われる場合があります。
- 表示される事業者情報は推定値であり、正確性を保証するものではありません。
